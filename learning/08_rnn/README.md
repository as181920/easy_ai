# 08 · RNN、LSTM 与 GRU

状态：课程大纲，尚无 RNN 训练实现。先修：01–03；文本任务加 07。下一章：[Seq2seq](../09_seq2seq/README.md)。

从 `h_t = f(W_x x_t + W_h h_(t-1) + b)` 开始，沿时间展开并共享权重。手算短序列 forward 和 BPTT；理解序列长度增加为何不直接增加共享参数量。再学习梯度消失/爆炸、截断 BPTT、隐藏状态重置，最后比较 LSTM/GRU 的门与状态。

计划实验：数字序列/有限状态规律 → 延迟复制 → 字符预测。比较 vanilla RNN 与门控版本在不同记忆长度的表现，记录任务指标、梯度范数及裁剪前后变化，不以裁剪后稳定替代原因分析。

可变长 batch 区分 padding、有效序列长度和 loss mask：padding token 不参与计分，不代表递归状态自动忽略它。跨独立样本必须正确重置状态；变长截断要明确 detach 的边界。Dropout 的作用位置与时间步间掩码是否共享需说明，不能机械把 MLP dropout 放到所有状态。

计划产出：时间展开图、每步隐藏状态、跨长度泛化曲线与裁剪消融。
