# 00 · 数学、数据与经典基线

状态：课程大纲，尚无本章独立实验。先修：无。下一章：[最小神经网络](../01_basic_nn/README.md)。

按以下顺序打基础：

1. 标量、向量、矩阵、张量；shape、广播、矩阵乘法、batch 与参数数量。
2. 函数、偏导、链式法则；从一元平方误差手算一次梯度下降，用有限差分检查导数。
3. 概率、条件概率、期望、方差；sigmoid/softmax、log-likelihood、交叉熵和熵。
4. 训练/验证/测试划分、数据泄漏、标准化、类别不平衡；准确率、precision/recall、回归误差和校准。
5. 线性回归 → 逻辑回归 → 两层 MLP；先做常量/多数类基线，再问增加非线性是否有帮助。
6. PCA 作为线性压缩基线、k-means 作为聚类基线；决策树/随机森林/梯度提升树作为表格任务选修基线。

计划实验：自己构造小数据，手算矩阵与 loss；对照解析/数值/自动微分；只在训练集估计标准化统计量，把同一变换用于验证和测试。生成数据时也要拆分独立样本，避免重复或同源样本跨集合。

完成标准：解释输入/输出 shape，区分参数与超参数、logit 与概率、拟合与泛化；能够选择与任务匹配的损失和基线。XOR 的 4 个点用于数学演示，不适合检验 dropout 或比较优化器的泛化能力。
