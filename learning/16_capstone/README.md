# 16 · 综合实验：完整学习闭环

状态：课程大纲。先修：00–03 与所选模型分支。选择一个项目完成，不要求把所有架构堆进同一个系统。

- 视觉：MLP → CNN → ResNet 分类，另用 AE 做压缩/去噪对照。
- 语言：字符/BPE → RNN → 小 GPT 的序列预测与生成。
- 表示学习：PCA → AE → VAE，分别检验压缩、表示与生成。
- 决策：Bandit → tabular Q-learning → 小 MLP 策略，检验回报和任务成功率。

统一交付：数据来源/划分与基线、模型 shape/参数量、训练配置、可重复入口、train/validation 曲线、逐层诊断、至少一个失败及修复、控制变量的消融、多种子波动、最终独立评估和可加载推理参数。

从小任务跑通开始；使用独立验证集选超参数，最终测试后不再反复按测试集调参。记录种子和环境，说明 CPU/CUDA 数值差异；如声称可恢复训练，实际验证优化器、scheduler、随机状态和数据顺序的恢复。

所有模型以任务证据评估：分类看泛化，AE 看独立重构/表示，生成看分布与多样性，RL 看独立环境回报。权重图只是诊断证据，不能替代这些目标。
