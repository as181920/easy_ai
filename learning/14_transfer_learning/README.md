# 14 · 迁移、微调与蒸馏

状态：课程大纲，尚无独立实现。先修：02–03 与选择的 CNN/ResNet/GPT 模型；不必先完成所有生成模型。

顺序：从头训练基线 → 预训练表示 + 冻结线性头 → 部分解冻 → 全量微调 → adapter/LoRA → 蒸馏。说明哪些参数训练、哪些冻结；LoRA 的低秩更新不等于基础权重本身必须稀疏。

计划实验先复用小数据自训 checkpoint，再选择适合课程资源的外部预训练模型。固定训练/验证/测试划分，对照同任务的样本量、性能、训练参数量和成本；迁移可能负迁移，不能只展示成功。

训练重点：optimizer 参数组、层间学习率、weight decay、冻结层的梯度/实际更新；CNN 冻结参数与 BatchNorm 统计更新是两回事。GPT 微调分别处理输入、attention mask 与 loss mask，明确哪些 token 有监督。

蒸馏区分 teacher 的软目标、temperature 与真实标签；检查 teacher 错误是否传给 student。预训练、监督微调、奖励优化的目标不同；后者在 [RL](../15_rl/README.md) 建立基础后再选学。

完成标准：checkpoint 能加载、推理行为可验证，冻结/可训练参数和实际更新一致；报告独立数据泛化与遗忘，而非只报告训练 loss。
