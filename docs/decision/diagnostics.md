该实验使用未校准的最终 choice checkpoint；不做再训练，不用 test 选择配置。

这说明该 checkpoint 在本次中文验证样本上的预测几乎不依赖 state，主要表现为候选先验。该结论不代表所有配置或训练预算下的架构都无法使用状态。
验证集 29.5% 与此前 test 的 25.5% 属于不同 split，不应混用。

目前可确认的数据限制：五语言的 1000 条训练行只有 200 个原始源样本，训练目标覆盖 49 个意图；负候选在数据准备时抽样一次，训练过程中保持固定。
100 步短文本 MLM 也不能证明已经学会跨语言语义。位置编码与 token embedding 的相对尺度、状态交互分支的梯度和表示是否退化，仍需单独测量，不能仅由曲线确定原因。

下一轮应优先验证条件信息是否真正进入决策：保留状态打乱和标签频率基线；检查表示尺度与梯度，并用同候选、不同状态、不同目标的对照样本检验。
随后扩大独立训练样本、控制标签分布和负例采样，保存最佳 validation checkpoint 并设置早停。
不应只通过增加层数、步数或平滑曲线来解释为效果提升；最终用独立测试集验证泛化。

## 后续受控排查

旧权重的 token embedding RMS 为 0.02048，原始 sinusoidal position RMS 为 0.70711，相差约 34.5 倍；抽样状态池化表示的平均余弦相似度为 0.99116。
交互分支的状态梯度非零，但这不等于有效利用了状态。

只把位置尺度降为 0.02，保持原来的 200 分组、MLM 100 步、候选 300 步，最终中文 validation 仍有 100% 的状态打乱预测一致率。
进一步加入 embedding LayerNorm 后，最终权重的原始准确率 33.5%、打乱后 24.5%，一致率 69.5%；但原始 NLL 2.49626，差于标签频率基线 1.90706。
因此输入归一化改善了这个实验的状态敏感性，却没有充分解决学习质量问题。

扩大到 2000 个训练源分组（五语言 10000 行），重新自训 8000 词 native BPE，跳过 MLM，从随机权重训练 1000 步，启用标签平衡与动态负例，仍出现状态忽略。
它使用相同的旧 validation/calibration/test 文件，未向训练加入这些分组；最佳 validation 在第 400 步，中文准确率 20.5%，打乱状态后仍为 20.5%。
这排除了“只要多下载一点数据、增加步数就会自然好转”的简单解释，但多项训练设置同时变化，不能从中单独归因于数据量。

同一请求下，近似的 `score(state, candidate) = a(state) + b(candidate)` 会在候选 softmax 中抵消共同的 `a(state)`。
旧的交互网络并非数学上只能表示这种形式，但需要警惕它在训练中退化到这种候选偏好。
因此新增显式乘积/差值的 matching 打分头做对照，继续保留自动消融，而不是通过固定案例的规则硬改概率。

## 改进配置的结果与边界

`runs/decision/expanded-matching`：使用 `config/decision/massive.yml`，四层 encoder，输入归一化，matching 头，随机初始化后直接做候选监督；训练 2000 源分组 × 五语言，native BPE 自训 8000 词（模型 embedding 容量仍为 32000），动态负例、标签平衡、32×1 batch，共 1000 步。
训练约 125 秒；包括诊断、校准、测试、报告的全流程约 208 秒。原始压缩包已有本地缓存，本次计时不包括下载和数据准备。
全部语言 validation 的最佳 NLL 为 0.81778（第 700 步）；校准和 test 使用该权重，不使用最后一步。

中文 validation（200 源分组，未校准）：

| 条件 | Accuracy | NLL | 与原预测一致率 |
| --- | ---: | ---: | ---: |
| 原始 state | 76.0% | 0.78400 | 100% |
| 打乱 state | 21.5% | 3.82893 | 24.5% |
| 常量 state | 19.5% | 4.12235 | 21.0% |
| 新训练集标签频率基线 | 33.0% | 1.80756 | 29.5% |

这次有证据表明模型在这个任务上有效使用了状态，而不只是调整候选先验。旧/新消融的 shuffle seed 不同，不能把打乱结果当作严格的单因素比较。
旧模型与新配置同时改变了训练样本、分词、预训练阶段、打分头、学习率和 microbatch；不能把所有收益都归于某一个改动。

独立 test：1000 行 / 200 源分组，五语言，八个采样候选；accuracy 75.6%，NLL 0.73891，Brier 0.35221，ECE 0.04979。
中文 75.0%、英文 80.0%、日文 75.5%、西班牙语 77.0%、阿拉伯语 70.5%。仍不是全 60 类官方任务，也不是通用推理评估。

用户给出的三个否定语义例子另外保留为手工探针（没有加进训练），使用校准后的新权重实跑：

| state | P(会迟到) | 最终选择 |
| --- | ---: | --- |
| 来不及了要迟到了 | 0.34247 | 不会（错） |
| 来得及不会迟到了 | 0.31155 | 不会 |
| 不会迟到了 | 0.26221 | 不会 |

所以这组否定语义检查**仍未通过**；修正状态依赖不等于获得任意问题的理解能力。
MASSIVE 训练中 question 基本固定为 Intent?、候选是英语意图描述，无法据此声称学会中文“会/不会”等开放候选判断。
后续这类能力需要包含问题变化、蕴含/矛盾/未知、否定与肯定对照的多语言监督数据，并单独留出测试集。
在业务中应先把当前权重限定为已训练的意图选择；不靠温度、阈值或几个关键词规则伪装语义能力。
